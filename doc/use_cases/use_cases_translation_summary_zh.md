## 3. 跨文档能力关系

这些用例共同描述了 Nav2 从“知道自己在哪里”到“安全到达目标”的能力链：

1. **定位是导航的基础**：室内定位和室外定位分别要求机器人在对应环境地图中获得自身位置。
2. **导航负责目标到达**：室内导航和室外导航在定位基础上，要求机器人自主前往用户指定位置。
3. **安全约束贯穿规划与控制**：碰撞规避处理实时人员和物体；禁行区域处理地图中预先定义的危险区域。
4. **多层空间扩展二维导航**：多层建筑导航在平面导航之外引入楼梯、坡道和电梯等跨楼层通道，并要求这些通道可以由用户或其他程序配置。
5. **总览与模板提供组织方式**：`README.md` 给出场景分类，模板规定每个用例至少说明目标、必要性、交互和非功能性要求。
