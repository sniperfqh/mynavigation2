# myworld3：当前 Gazebo 真实激光候选地图

状态：**已按用户要求用于固定路径仿真默认地图，验证不足保留。**

地图来自原 `myworld2/world_only.sdf` 的 GPU 激光与 SLAM Toolbox，未用几何切片、理想激光或真值生成地图。建图遍历 15 个目标并返回起点，观测约 245.7 m²；未观测区域保持未知。分辨率约 0.01 m，原点完整保存，灰度 205 与 `free_thresh=0.196` 配套，避免把未知区域加载为自由空间。

采用 SLAM 原生坐标。当前首帧原生位姿与已有 Gazebo／odom 坐标一致，仍为 `(-2.8, -1.7, 2.557722257927678)`；不把图片原点当作机器人位姿，也不强行将首帧改为零。`params/myworld3.yaml` 保留现有运动控制参数。

## 独立验证

六处、每处三个朝向，完整 720 束真实激光；使用固定一次的世界／地图关系，真值仅用于离线诊断。

- 激光端点到地图占据轮廓：各朝向中位数均为 0，P95 最大 30 mm，地图外端点为 0；这是 AMCL likelihood_field 使用的匹配距离。
- 原方案的严格射线首次命中：仅 9/18 项通过，整体 P95 0.261 m；**未通过原地图验收门限**。是否采用端点距离作为验收依据，等待用户选择，不将原失败项改写为通过。
- 运行态旧导出版本曾将未知灰度误读为自由，已修正。新旧 PGM 字节一致，所以独立几何数据可复算；旧版本停车数据不计入正确版本验收。
- 正确版本、原控制参数的 0.2 m/s 停车：前进通过，倒车 Action 成功并停稳，但停后 1 秒定位误差最大 12.31 mm，未达到 10 mm 标准。测试在 1/2 后停止，未完成每方向 5 次，不宣称物理精度。
- 生命周期管理器在 SIGINT 停机阶段出现 -11，未排查；完整规控入口在默认中间件下还遇到启动服务超时。临时 Cyclone DDS 本机单播配置使运动测试进入执行，不代表生产中间件已修改或默认启动已验收。
