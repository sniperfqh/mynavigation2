# Action测试：速度停稳与定位采样分开验收

源码工具：tools/action_only_speed_sweep.py，窗口计算：tools/stationary_acceptance.py。新协议为separated_velocity_pose_v2，不替换历史严格连续窗口结果，不修改控制器成功判定。

速度停稳独立于地图TF：新鲜/odometry与/motion_state均满足线速度≤0.01m/s、角速度≤0.05rad/s，/cmd_vel零输出，连续1秒；反馈接收及时间戳年龄均≤0.25秒。仍在运动、速度反馈失效或观察间隔超过0.2秒重置停稳计时，短暂定位失效不重置。

定位以最近1秒采样窗单独评估：每个采用的TF样本年龄0～0.25秒，至少10个有限值样本，有效时间覆盖率≥80%，有效样本最大缺帧间隔含窗口边界≤0.2秒。覆盖率按查询间隔的有效时间计算，不按样本数量。缺失区间不插值、不补发旧位姿；该窗口不称为定位连续有效1秒，无法证明缺失区间内误差。

定位质量合格才按采用样本最大误差≤10mm报告采样精度PASS/FAIL；不足则precision_status=UNAVAILABLE、error_mm=null，observed_error_mm仅为可见数据，不算通过。Action结果和原始速度保存。12秒仍无合格定位窗时，保留独立停稳证据，不丢弃已完成任务；禁止继续发下一任务。

stationary_acceptance字段记录停稳起点、覆盖率、最大缺帧间隔、采用样本及窗口起止。移动阶段仍保留连续1秒无有效遥测的取消规则，不放宽生产控制器TF新鲜度。此工具默认执行用户已定义的0.2～1.5m/s、两程前进28例，需已有仿真/定位、8mm入口和0.03m低速裕量，输出目录为唯一位置参数。工具不启动或重启后台；导航测试暂停时不得运行，只做离线回放。

2026-10-13离线回放：历史有噪声第4例在新口径下约1.03秒确认速度停稳，约2.63秒取得定位窗；覆盖率80.4%、最大缺帧87ms，采用样本最大误差9.42mm。结果标为新协议回放，历史未验收状态保持。前三例回放误差9.40/12.82/11.15mm，未放宽精度阈值。4项纯Python边界测试通过；实际新工具运行仍未验证。

2026-10-15运行记录：有噪声正式28例Action均成功，采样精度20/28、原始命令与反馈蠕动各≤4秒26/28、联合19/28。在线sampled_creep字段会漏算定位采样间隙，最终统计需从原始速度回调离线复算。关闭人工雷达噪声后重测由用户暂停，发送7例均成功，其中6例完整采集，第7例仅查询原UUID确认成功、测量不可评价，剩余21例未发送。暂停后不运行新Action；后台仿真定位保留，车辆反馈停稳。完整原始报告保存在外层项目readme/test_reports/，不随本子仓库发布。结果是地图TF采样精度，不是真值或实车验收。
